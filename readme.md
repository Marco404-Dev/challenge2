# Entre sueños — Challenge de ciclo de sueño

## Abrir la página sin instalar nada

Descarga o descomprime la carpeta y haz doble clic en `index.html`. Funciona sin Node.js, npm ni servidor.

## Publicarla con GitHub Pages

1. Sube el contenido al repositorio GitHub.
2. En **Settings > Pages > Build and deployment**, elige **GitHub Actions**.
3. En **Actions**, verifica que el flujo «Publicar en GitHub Pages» haya terminado correctamente.
4. En **Settings > Pages** aparecerá la URL pública.

## Contenido

La página incluye vecino más cercano, regresión lineal, gráfica interactiva, validaciones y exportación CSV. Los datos son solo de carácter educativo y no son recomendaciones médicas.

El notebook de Colab está en `notebooks/Challenge_Marco_sueno.ipynb`. Los archivos `model.js`, `app.js` y `styles.css` se conservan como referencia, pero `index.html` ya es independiente de ellos.
